# Specs

The documents in this directory are **working artifacts, not commitments**.

Each spec (requirements, design, task ledger) was written to drive one
feature to completion. It records the state of thinking at the time the
feature was built — including options that were considered and constraints
that have since been superseded — and is kept because that reasoning is
useful to the next change. Specs are not product commitments, roadmaps, or
API documentation. The contract Tokeira ships is the code, the documents
under `docs/`, and the published conformance evidence.
