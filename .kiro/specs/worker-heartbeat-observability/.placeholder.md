This directory now contains the owning requirements, design, and task plan for process-local worker-heartbeat observation, metrics, shutdown removal, Nexus-poll ingestion, and the `DescribeWorker` / `ListWorkers` inventory APIs. It supersedes the original placeholder created by `temporal-api-v1.62-sync`; heartbeats remain volatile observations and are intentionally not persisted.
