# Behavioural conformance ledger

This ledger records decision comparisons against the independent Temporal v1.31.0
model. Every decision verdict here is **provisional**. No recorded corpus exists
yet, and no row claims calibrated behavioural coverage. Source-only boundary
rules retain their catalog reason; they do not supply RPC scenario evidence.

The four decision verdicts are `agrees`, `differed and fixed`,
`differs, ignored with reason`, and `not yet tested`. Agreement requires every
named comparison to have run and passed. An ignored difference requires every
named ignored comparison to have executed and failed; skipping it is insufficient.
Missing, skipped, erroneous, unexpected, or stale outcomes render `not yet tested`.
The reason retains the maintained explanation and any branch gaps.

[Decision evidence](../../crates/tokeira-behaviour-harness/decision-evidence.json)
contains maintained counterparts, tests, reachable RPCs, reasons and correction
commits separately from imported run observations. The
[rule catalog](../../crates/tokeira-behaviour-model/rules.json) supplies source
citations and model support. The [harness README](../../crates/tokeira-behaviour-harness/README.md)
documents checks and regeneration. SHA-256 identifies each imported JUnit report
and the complete rule at import; it does not claim a production revision or corpus
calibration. The report must come from a run against that catalog.

Only content between each `BEGIN GENERATED` / `END GENERATED` marker pair is
generated. Explanatory notes outside those blocks are retained byte for byte.
