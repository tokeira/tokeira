> This is the complete source-aware configuration denominator for Tokeira's Temporal server v1.31.0 compatibility target. It records what Temporal exposes and Tokeira's treatment of each item; it is not a list of raw keys accepted by `tokeirad`.

## Method and authority

The checked audit reads production, non-test Go files from the local Temporal source at tag `v1.31.0`, parses `New*Setting` declarations with the Go AST, and records constructor, scope, value kind, default expression, and source anchor. The immutable extraction snapshot is joined one-to-one with an owner-authored classification ledger. Duplicate, missing, extra, non-literal, or unresolved entries fail verification before this document can be generated.
