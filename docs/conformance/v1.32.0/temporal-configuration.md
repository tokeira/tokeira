# Temporal v1.32.0 configuration surface

> This is the `TEMPORAL_SERVER_TARGET` denominator for **v1.32.0**. Tokeira's advertised compatibility claim (`TEMPORAL_SERVER_COMPAT`) remains **v1.31.0**. Target defaults and migration owners below record required work; they do not assert that behavior changes have landed. This is not a list of raw keys accepted by `tokeirad`.

## Method and authority

The checked audit reads production, non-test Go files from the local Temporal source at tag `v1.32.0`, parses `New*Setting` declarations with the Go AST, and records constructor, scope, value kind, default expression, and source anchor. The immutable extraction snapshot is joined one-to-one with an owner-authored classification ledger. Duplicate, missing, extra, non-literal, or unresolved entries fail verification before this document can be generated. Removed keys are audited separately and excluded from the denominator. Their retained conformance overrides remain checked against the actual registry until the owning delta migrates the consult site. Unchanged treatments describe the current v1.31.0 profile.
